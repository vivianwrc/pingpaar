# Pingpaar

Eure gemeinsame Paar-App mit Pinguin Kiesel.

**Live:** https://vivianwrc.github.io/pingpaar/

- `index.html` – die App
- `config.js` – Verbindung zu Supabase (Frankfurt, EU)
- `supabase.sql` – Aufbau der Datenbank
- `vendor/` – Bibliotheken (Supabase, three.js)

Änderungen auf `main` sind nach 1–2 Minuten automatisch auf der Webseite.
